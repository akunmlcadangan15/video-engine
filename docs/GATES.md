# Gates

Pre-flight target: < 5 s total (measured stage times: `--timing-tsv`). Levels: `pass`, `fix` (auto-fixed), `info`, `warn`, `skip`, `fail`. Any `fail` stops `build`.

Severity (`video_engine/gates/severity.py`): technical gates (assets, output integrity, decode, loudness, licence and credits, caption bounds and legibility, factual pins) keep their level. Style gates (H01, C01, C02, V01, N01, P01, P02, K01, K02, D01, D02, S01, AS01, AS02, AS03, AS05, AS06) block only when required (profile `[gates] require` + timeline `gates.require`); a fail of a style gate that is not required is reported as warn; so is a fail of a technical gate in the profile's `[gates] advisory`. Geoverum requires S01 and lists R64, E01, R56, T01, R44, AS04, F03 and L02-L10 (except L06) as advisory. `build_report.json` -> `gates`: `required`, `fails`, `warns`, `waived` (each row: `gate`, `class`, `level`, `message`, `seg`, `frames`, original level in `waived`).

| layout | L02 | Pin label box + `edge_clear` crosses no region edge; area labels inset `area_inset` inside their region (or outside with a leader); fail otherwise. A label hidden by the planner = warn. |
| layout | L03 | Per frame <= `texts` texts, <= `labelled_pins` labelled pins, <= `routes` routes, <= `animating` tweens, at most one number >= 100 px, at most one region at full fill; fail otherwise. |

| layout | L08 | Label moves: at most `moves_per_shot` non-urgent moves per shot, never two within `move_gap_s`; fail otherwise. |
| layout | L09 | Highlighted (full) region fill under the caption box <= `caption_ground` of its area; fail otherwise. |
| layout | L10 | Hold >= max(`min_hold_s`, chars / `chars_per_s`) (to the segment end for the last span), exits `exit_min_s`-`exit_max_s`, entries after the camera settles and after the exits, stagger >= `stagger_min_s`; fail otherwise. |

| props | F02 | Source width (model props: sprite size) / largest on-screen width over the shown frames (zoom, depth and pop included): fail < 1.0x, warn < 1.5x. |
| props | F03 | On every shown frame the prop box (rotated ink box plus shadow) intersects no pin head, label, title, figure, card, heading, note or area label (beats: layout items of every frame; DOM rects at the probe seeks) and no caption shown on that frame; fail otherwise. No finding without the key. Gate code: `video_engine/gates/audio_source.py`. |
| delivery | A01 | Final file at `target_lufs` +/- `tolerance_lu` and true peak <= `true_peak` (default profile: -14.0 LUFS +/- 0.2 LU, -1.5 dBTP). Values recorded in `build_report.json` -> `loudness`, with the loudness range `measured_lra` (information only). |
