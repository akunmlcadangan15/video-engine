# Channel profiles

- Files: `profiles/default.toml` holds the engine values; `profiles/<channel>.toml` lists only the keys a channel changes. Tables merge key by key.
- Precedence: `default.toml` < channel profile < project values (`caption_style` keys, `audio_chain.target_lufs` / `true_peak` / `lra`).
- Tables:

| Table | Keys |
|---|---|
| `description` | free text |
| `[caption_style]` | Python caption keys (`auto_place`, `clearance`, `fixed_y`, `max_bottom_y`) and any Rust `Style` field (see Captions) |
| `[audio]` | `target_lufs`, `true_peak`, `lra`, `tolerance_lu` (A01 tolerance), `require_source` (`"epidemic"` or absent: source every music and SFX file must have, gate A02; docs/SOUND.md) |
| `[draft]` | `min_seg_s`, `max_seg_s` (pause segmenter and draft prompt segment length), `rules` (prompt rules appended after the engine rules, numbered from 6), `map_path` (true = the draft schema offers `map_path` camera keys for map segments) |
| `[theme]` | Renderer values written into the HyperFrames scene (`theme`): `camera_drift_per_s`, `camera_start_speed`, `camera_end_speed`, `whip_s`, `whip_blur_px`, `region_fill_opacity`, `region_edge`, `region_edge_px`, `region_glow_px`, `pin_style`, `pin_colour`, `label_font`, `pin_label_px`, `route_colour`, `route_width_px`, `route_dash_px`, `route_gap_px`, `route_arrow_px`, `route_draw_s`, `region_glow_alpha`, `title_font`, `title_px`, `title_glow_px`, `title_tint`, `text_outline_px`, `text_outline_colour`, `text_outline_alpha`, `text_shadow_dy_px`, `text_shadow_blur_px`, `text_shadow_alpha`, `figure_px`, `counter_s`, `number_group`, `number_decimal`. A theme font role (`label_font = "script"`, `title_font = "title"`; a year figure always uses the serif) adds its font file to the HyperFrames build and cache key. `palette` and `[theme.entities]` resolve entity colours into the scene elements and are not in `theme`. |
| `[motion]` | Named motion tokens: `ease_out`, `ease_in_out`, `ease_drawer` (CSS cubic-bezier, Emil Kowalski), `micro_frames` (4), `overlay_frames` (7), `panel_frames` (12), `stagger_frames` (2) at 30 fps, role eases `entrance` (`power2.out`), `move` (`power2.inOut`), `exit` (`power2.in`), `entrance_scale` (0.96) and `overlay_fade_s` (0.20). The role names keep the engine look; set one to a token curve to adopt it. The HyperFrames scene carries `theme.motion`; native drawn overlay fades read `overlay_fade_s`. A default `[motion]` table is left out of the profile hash. |
| `[camera]` | HyperFrames camera pulses inside every drift (the camera waiting on a view): `pulse_zoom` (ln zoom of a pulse, 0-1; 0 = no pulses), `pulse_s` (length), `pulse_gap_s` (minimum drift before, between and after pulses), `pulse_pan` (frame-centre shift of a pulse away, frame widths, sides alternate), `pulse_ease` (CSS cubic-bezier), `pulse_anchor` (screen point, frame fractions, that stays put), `pulse_direction` (`in` = push in then back, `out` = pull out then back), `max_zoom` (deepest camera zoom: camera keys, layout fit and draft `map_path` stop there; 1-64). Defaults: 0, 0.8, 0.6, 0, [0.3, 0, 0.15, 1], [0.5, 0.5], `out`, 4.0. A default `[camera]` table is left out of the profile hash. Pulse values are part of the HyperFrames scene theme (`camera_pulse`) only when `pulse_zoom` > 0. |
| `[grade]` | Default full-frame grade of every segment and beat without its own (same keys as segment `grade`; `lut` relative to the profiles directory). Absent = no grade; absent leaves the profile hash unchanged. |
| `[transitions]` | Segment-boundary transitions drawn from the segment files and laid over them by the final mux: `kind` (`cut`, `zoom_whip`, `page_turn`; default `cut`), `by_type` (visual type -> kind; the incoming segment's type wins, then the outgoing one's), `whip_out_s` (0.1), `whip_blur_in_s` (0.1, <= `whip_in_s`), `whip_in_s` (0.4), `whip_scale` (1.3), `whip_blur` (0.12), `page_s` (0.4). zoom_whip: the outgoing shot pushes in to `whip_scale` over `whip_out_s` with a radial blur rising to `whip_blur`, the incoming shot settles from `whip_scale` to 1 over `whip_in_s` with the blur fading over `whip_blur_in_s`. page_turn: the outgoing last frame folds away from the bottom-right corner over the incoming shot for `page_s`. No transition = the concat of the segments unchanged. |
| `[watermark]` | Optional channel mark burned into the final video by the composite pass, above the captions, in every segment: `text` (one line, 1-40 chars), `font` (`inter` = Inter Bold, `title` = Archivo Black), `px` (16-120, px at 1920 height, default 36), `colour` (`#rrggbb`, default white), `opacity` (0-1, default 0.85), `shadow` (soft dark shadow, default true). The text's right edge sits on the right edge and its top on the top edge of the safe area (60 px sides, 100 px top). Absent table = no watermark and the mux graph without overlay. Not in any segment cache key. |
| `[sound]` | Optional SFX cues, one per render event (`video_engine/sfx.py`), and the mixer (`video_engine/mixer.py`). Mixer keys: `duck_db` (music gain while the voiceover speaks, -40 to <0, default -12), `duck_attack_s` (ramp down before a phrase, default 0.15), `duck_release_s` (ramp up after it, default 0.4), `duck_merge_s` (word gaps up to this long stay ducked, default 0.5), `fade_in_s` / `fade_out_s` (music, default 0.3 / 1.0). Speech spans come from the voiceover word timestamps; ducking applies when `audio_chain.auto_ducking` is on and a voiceover is set. `[sound.events]`: render event -> SFX kind; events `pin` (teardrop: when the drop first touches its shadow, 0.22 s after it appears; dot: when it appears), `region` (fade-in start), `route` (mid-draw), `whip` (mid-move), `label` (HyperFrames card, drawn native overlay), `title` (entrance), `figure` (bounce figure entrance), `counter_tick` (each frame on which a counter's shown text changes). `[sound.kinds.<kind>]` for every mapped kind: `gain_db` (-60 to 0), `align` (`onset`: the file starts on the event; `peak`: its loudest sample lands on the event, default `onset`), `max_s` (cue length cap, default 2.0). Kinds: `pop`, `tick`, `whoosh`, `click`, `beep`, `counter_tick`, `impact`, `riser`. Unknown events or kinds and events mapped to a kind without a table are errors. |
| `[gates]` | `require`: style gate ids (H01, C01, C02, V01, N01, P01, P02, K01, K02, D01, D02, S01, AS01, AS02, AS03, AS05, AS06) whose fail findings block a build. Every other style gate reports at most warn. Technical gates block on fail unless listed in `advisory`. `advisory`: technical gate ids this channel lowers from fail to warn (never T02, R07, R14, A01, A02, W01, R38, R56px, M01, M03, G01, L22). AS04 is technical-class and a profile raises it with `[gates.anti_slop.levels] AS04 = "fail"`. |
| `[gates.<name>]` | Channel style gates (table below). Absent table = gate off; the default profile has none. |
| `[gates.anti_slop]` | Anti-AI-slop rules `AS01`-`AS06` (table below). `level` (default `warn`) and per-rule `[gates.anti_slop.levels]`; `panel`, `copy`, `motion`, `read_time`, `source_tells`, `palette` switch rules on, plus `em_dash_max`, `em_dash_per_500`, `aphoristic_min`, `buzzwords`, `chars_per_s`, `min_read_s`, `forbidden_hues`, `side_strip_px`, `clip_vertices`. Taste rules stay warn unless a profile raises them. Geoverum raises AS01 to fail and requires it; AS02-AS06 stay warn, including technical-class AS04. |
| `[resources]` | `workers` (0-64, 0 = auto): shared worker budget of a build (see Resources). `VIDEO_ENGINE_WORKERS` overrides it. |

| Table | Gate | Keys | Rule |
|---|---|---|---|
| `[gates.hook]` | H01 | `vo_warn_s`, `vo_fail_s`, `caption_warn_s`, `caption_fail_s`, `graphic_warn_s`, `graphic_fail_s`, `open_on_moving_map` | Narration start (end of a leading pause in the voiceover), first caption start and first pin / card / drawn overlay: later than the warn value = warn, later than the fail value = fail. `open_on_moving_map`: segment 0 must be HyperFrames with a `camera_path` or a camera preset other than `static`, else fail. |
| `[gates.cuts]` | C01 | `warn_per_10s`, `fail_per_10s`, `first_warn_s`, `first_fail_s` | Shot changes = segment boundaries; a boundary is a hard cut unless profile `[transitions]` draws a transition there (camera moves, pans, zooms, pulses and whips inside a segment are not shot changes). Hard-cut rate above `warn_per_10s` = warn; shot-change rate above `fail_per_10s` = fail; first hard cut earlier than `first_warn_s` = warn; first shot change earlier than `first_fail_s` = fail. A transition window that leaves its two segments or overlaps the next window = fail. |
| `[gates.visual_type]` | V01 | none | A shot change (hard cut, zoom whip or page turn, named in the message) between two segments of the same visual type = warn; between two HyperFrames segments on the same map asset = fail. |
| `[gates.novelty]` | N01 | `max_gap_s` | Gap between new on-screen events (segment start, pin, card, drawn overlay start, `camera_path` key) longer than `max_gap_s` = warn. |
| `[gates.camera]` | P01 | `hold_warn_s`, `hold_fail_s`, `moving_warn`, `still_zoom_ln_s`, `still_pan_w_s` | Planned camera per frame (HyperFrames camera legs, native `camera_move` windows; native footage without a camera move is not counted; transition frames count as moving): a frame is still when its zoom speed is below `still_zoom_ln_s` (ln scale / s) and its frame-centre speed (2D) below `still_pan_w_s` (frame widths / s). A run of still frames longer than `hold_warn_s` / `hold_fail_s` = warn / fail; moving fraction below `moving_warn` = warn. |
| `[gates.camera]` | P02 | `min_drift_per_s` | Theme `camera_drift_per_s` below `max(min_drift_per_s, still_zoom_ln_s)` = fail (waits between camera moves would be still). Absent key = no P02. Geoverum: 0.06 ln/s. |
| `[gates.keyword_return]` | K01 | `hook_s`, `end_s`, `min_chars` | No word (>= `min_chars` letters) of the on-screen text or captions of the first `hook_s` on screen in the last `end_s` = warn. |
| `[gates.keyword_return]` | K02 | `hook_s`, `end_s`, `min_chars` | No hook keyword of the first `hook_s` is still on screen on the final frame = fail (absent hook keyword = warn). `end_s` is reserved for the last-seconds variant. |
| `[gates.cta]` | C02 | `phrases` | A call-to-action or end-card phrase in on-screen text or captions (whole words, case-insensitive) = fail. |
| `[gates.duration]` | D01 | `min_s`, `max_s` | Total length outside `min_s`-`max_s` = warn. |
| `[gates.duration_exact]` | D02 | `target_s`, `tolerance_s` | Total length outside `target_s` +/- `tolerance_s` = fail. |
| `[gates.geo]` | G02 | `require_land` | Region polygons must have area and not cross themselves; a beat pin must lie inside its beat region; a pin label naming a region must sit inside it; with `require_land`, a geographic pin over water = fail (warn without it). Uses `/workspace/geo-library` Natural Earth land when present; absent library skips the land part. |
| `[gates.silence]` | S01 | `max_gap_s`, `threshold_db` | Final file: a gap below `threshold_db` (ffmpeg `silencedetect`) longer than `max_gap_s` = fail. |
| `[gates.anti_slop]` | AS01 | `panel` | A drawn `lower_third` or `text_card` uses a left accent strip on a dark panel: the confirmed decorative side-strip panel. Warn by default (Geoverum included); a profile makes it blocking with `[gates.anti_slop.levels] AS01 = "fail"` plus `[gates] require = ["AS01"]`. Use a plain panel or a `label`. |
| `[gates.anti_slop]` | AS02 | `copy`, `em_dash_max`, `em_dash_per_500`, `aphoristic_min`, `buzzwords` | On-screen and caption copy: em-dash saturation (>= `em_dash_max`, or >= 2 above `em_dash_per_500` per 500 characters), a listed buzzword, >= `aphoristic_min` "No ..." rebuttal endings, or "theater" = warn. |
| `[gates.anti_slop]` | AS03 | `motion` | `[motion] entrance` is an ease-in, `entrance_scale` < 0.9, `[layout.fly] ease_in` is an ease-in, or a figure uses a bounce entrance = warn. |
| `[gates.anti_slop]` | AS04 | `read_time`, `chars_per_s`, `min_read_s` | A drawn overlay text is on screen shorter than max(`min_read_s`, characters / `chars_per_s`) = warn; technical-class, a profile may set `levels.AS04 = "fail"`. |
| `[gates.anti_slop]` | AS05 | `source_tells`, `side_strip_px`, `clip_vertices` | Composition sources under the project and the built HyperFrames HTML: gradient text, `backdrop-filter` glass, a `border-left/right` wider than `side_strip_px`, `repeating-linear-gradient`, zero-offset glow, an organic/high-vertex `clip-path`, or a `kicker`/`eyebrow` class = warn per finding. Engine-generated template effects and markup (`MO.*` motion tokens, whip blur, built-in `lower_third` markup) are allowlisted; only project content is flagged. |
| `[gates.anti_slop]` | AS06 | `palette`, `forbidden_hues` | A literal colour in a composition source or the built HyperFrames HTML whose hue is in a forbidden AI-tell range (default violet 260-310, cyan 170-197) and is not a declared brand colour = warn. Engine-generated template content is allowlisted. |

- Warn thresholds must not be beyond fail thresholds; unknown gate tables or keys are errors.
- `[legibility]` (optional): adaptive map text for teardrop labels, title, years, counters and area labels (water names blue italic): polarity, sepia ink, background-tinted halo that keeps counters open, escalation, stability schedule, overlay muting, cased pins, routes, region outlines and leaders, and gate R64. Keys and rules: docs/SPEC.md, section F. Absent = theme text paint and R64 off.
- `[print]` (optional): printed typography and map grade: the map surface (paper or dark imagery) fixes the text polarity; paper text is ink multiplied into the map (no halo, glow or box), EB Garamond titles inside their region, a centred Playfair year, Cinzel headings with rules, EB Garamond Italic pin labels above the pin on a leader, Kalam hand notes; regions with a multiplied fill and solid edge; paper texture and grain; gates T01 and B01 clearance. Keys and rules: docs/SPEC.md, section F2. Absent = theme typography.
- Profiles: `default` (engine values, every anti-slop rule warn, no channel-required style gates), `geoverum` (white Inter Bold 84 (A/B candidates 84 / 92 / 104), no outline and never a backing box, soft shadow 0 3 px blur 4 at 55 %, no highlight, max 2 words, `fixed_y` 1382 (about 0.72 H), `max_bottom_y` 1480, `auto_place` true inside `place_band` 0.60-0.76 H, `clearance` 0, default loudness (-14 LUFS, -1.5 dBTP), music and SFX from Epidemic Sound only (A02), segments 0.8-30 s with free cuts, hard cuts with a 0.2 s state dissolve between segments on one map, no page turns or map morphs, camera zoom up to 16x, `[render]` HyperFrames `high` CRF 8, intermediates CRF 8 medium, final CRF 12 slower capped at 25 Mb/s, map JPEG q95, every style gate on except C01 cut rate and V01 visual type, only S01 required, R64, E01, R56, T01, R44, AS04, F03 and L02-L10 (except L06) advisory, anti-slop AS01-AS06 warn, SFX cues (pin and figure `pop`, label and region `tick`, route and whip `whoosh` with the peak on the move, `counter_tick` per counter step, title `impact`), music ducked -12 dB under the voiceover with keyframed ramps, camera drift 0.06 per second (counts as P01 motion), muted OKLCH entity palette of 17 colours with six unpinned (teal, umber, wine, mauve, jade, olive), adaptive legibility `[legibility]` with R64, printed typography `[print]`, watermark "Geoverum" in Inter Bold 40 px, white at 85 % with a shadow).

- Global safety limits: a profile may set `audio.true_peak` and `audio.tolerance_lu` only at or below the default profile value; a looser value is an error. Gates T02, R07, R14, A01, A02, W01, R38, R56px, M01, M03, G01 and L22 (`profiles.NEVER_ADVISORY`) and post-render QA are identical for every profile; no `[gates] advisory` list can lower them.
- Unknown keys, wrong types, `clearance` < 0, `fixed_y` or `max_bottom_y` outside 0-1920 or `lra` <= 0 are errors naming the profile.
- Segment cache keys contain the profile values that reach the segment's renderer: the HyperFrames key contains the scene, which holds `theme`, `print`, `layout` and `legibility`, plus the map derivative key and the toolchain identity (docs/RUST.md, Cache-key rules); native segment keys contain no profile value (no profile key reaches the native renderer). `build_report.json` -> `profile` records the name and the BLAKE3 hash of the merged profile.
