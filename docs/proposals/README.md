# Proposals

Ideas that are **not built**. A proposal states what is known, what is not, the options, and a recommendation.
It is not part of the specification: the engine does what [SPEC.md](../SPEC.md) and the reference documents say.
When a proposal is built, its facts move into the reference documents and the proposal is deleted.

|---|---|
| [formats-and-fps.md](formats-and-fps.md) | What stops the engine from rendering other frame sizes and fractional frame rates for other channels? |
| [render-lock.md](render-lock.md) | Can the single global render lock be replaced by a lock that allows safe parallel builds? |
| [landscape.md](landscape.md) | How does the engine render landscape 16:9 at 1080p, 1440p and 4K while Shorts stay portrait? |
