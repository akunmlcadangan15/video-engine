# Tests

`python -m pytest` (about 1570 tests; DOM/Chrome tests need `vendor/node` and `vendor/chrome` from `engine doctor --install` and skip with that hint while the toolchain is missing; `VIDEO_ENGINE_REQUIRE_TOOLCHAIN=1` makes them fail instead, as in the nightly CI job). All test scratch (scratch root, cache, generated assets, `tmp_path` base) lives in `/tmp/video_engine_test_shm/pytest-<pid>/` (override with `VIDEO_ENGINE_SHM_TEST`) and is removed when the session ends; the parent is removed only when the session created it and it is empty; a session removes only its own root, so simultaneous sessions do not interfere (`tests/test_scratch_cleanup.py`). Every gate has labelled GOOD and BAD cases. `tests/test_gates_layer2.py::test_R63_bad_caption_too_close_to_pusat_kota_pin` and `..._good_caption_auto_placed_away_from_pin` cover the caption vs "Pusat Kota" pin case; `test_R63_dom_demo_end_to_end` runs the real DOM probe on a synthetic project with and without auto placement. AI tests use mocks (Gemini client, OpenAI-compatible HTTP post) and agent bundles on disk; no network. Rust: `cd rust/hypoverum_core_rs && cargo test --release --no-default-features` (49 tests; set `TMPDIR=/dev/shm/video_engine/tmp`).
